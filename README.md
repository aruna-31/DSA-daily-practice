# DSA Daily Practice

> A growing collection of Data Structures and Algorithms practice problems for technical interview preparation.

This repository tracks hands-on problem solving across common coding-interview patterns. Solutions are organized by problem/topic so the progression remains searchable and reviewable.

## Current topics

- Arrays
- Binary Search
- Bit Manipulation
- Additional LeetCode topics as the repository grows

## Example problems

- Single Number
- Find Peak Element
- Single Element in a Sorted Array

## Purpose

The goal is to build pattern recognition, implementation speed, and consistent problem-solving practice rather than simply collect solutions.

## How to use

Each problem is stored in its own directory. Open a problem folder to inspect the solution and associated code.
